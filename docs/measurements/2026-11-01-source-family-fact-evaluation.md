# 새 원천 상품군의 고정 스타일 사실 검색 평가

기준 main `378de7f`, Python3.12.14·locked scikit-learn1.9.1에서 새 CC0 상품군6개를4fit/
2transform으로 나눴다. 목적은 실제 다른 상품군의 표현·OOV를 점검하고 사전 고정 사실 관련성을
검사하는 것이다. 서비스 B0/B1의 성능 비교나 사용자 만족도 개선 실험이 아니다.

## 원천과 동결

- 기존의 can/bottle 필수 발견 대신 양수 P2234/P2665·LIMIT10 조건을 사용했다. 첫 WDQS
  HTTP200 뒤 임시 조사 코드의 tuple 반환 처리 오류가 발생해 결과는 미확정으로 보존했다.
  오프라인으로 반환 계약을 확인/수정한 뒤 명시적으로1회 다시 조회했다. 총 발견 GET2회이며
  자동 retry·원천 오류/차단 우회가 아니다. 정상 응답1043B는8ID를 반환했다.
- 기존 strict wbgetentities 단일 GET(maxlag5·8ID·112755B)으로 revision/receipt를 확보했다.
  기존 원문 ID와 대조해 기존1/신규7이며, 이 중6개는 명시 상품군·1개는 브랜드 범위로 보류했다.
  발견/수집 성공은 SKU·권리/사실 전체·업무 매핑 승격이 아니다.
- [CC0](https://www.wikidata.org/wiki/Wikidata:Licensing),
  [P2665 허용 단위](https://www.wikidata.org/wiki/Property:P2665),
  [P2234](https://www.wikidata.org/wiki/Property:P2234)를 확인했다. 새6개의 도수는 generic
  percent라 volume-percent로 바꾸지 않았고, 포장별 용량 qualifier도 unknown으로 유지했다.
  제조사 페이지 교차 확인에서429가 있어 추가 요청하지 않았다. 외부 본문·맛/가격/이미지를
  dataset으로 수집하지 않고 source의 구조화 사실만 사용했다.
- 모델 실행 전13:52:20 UTC에 명세 hash/사실·그룹·질의/후보·정답·cutoff를 고정했다.
  source raw/revision·수집 receipt·검수/명세 hash와 결과 파라미터/원순위는 ignored에 보관한다.
  같은 입력으로 실행한 두 보고서 전체와 원래 frozen spec hash가 일치했다.

## 실제 관측과 분모

| 항목 | 결과와 해석 |
|---|---|
| 원천 grain | 이름이 구분되는6상품군/6그룹, 제조사1. 포장 SKU/업무 ID가 아님 |
| 학습/변환 | 각각4/2그룹. 전처리 fit은4개에만 적용 |
| 텍스트 표현 | 4×5/rank4. 학습 스타일4종·공통 제조사1토큰 |
| 학습 수치 | 도수·용량 각각0/4관측, all_unknown·비활성 |
| 변환 표현 | 스타일을 지원한1개는2토큰, 미관측 스타일1개는 OOV1·공통 제조사1토큰만 지원 |
| 독립 사실 명세 | 수동 P31 동일 관계. 입력 특성과 공유하는 사실 관계이며 사람 선호 정답이 아님 |
| 평가 질의 | 전체2, 양성1질의·후보4/양성1, 양성0질의1은 Recall/NDCG 분모 제외 |

| 양성 질의1개의 카탈로그 사실 관련성 | source-ID 참고순 | 표현 cosine순 |
|---|---:|---:|
| 관련 상품 위치 | 3위 | 1위 |
| Recall@1 | 0 | 1 |
| NDCG@1 | 0 | 1 |
| Recall@3 | 1 | 1 |
| NDCG@3 | 0.5 | 1 |

참고순은 기존 source 실험의 문자열 ID 정렬을 고정 대조군으로 썼다. 숫자 업무 ID의 서비스 B0나
운영 품질 기준이 아니므로 위 차이를 서비스 개선율로 계산하지 않는다. 미관측 스타일 질의는
학습 후보4개가 공통 제조사만으로 동점이었다. positive0인 이 질의의 실패 경계를 숨기거나
관련성0을 임의로1로 바꾸지 않았으며 원순위/score는 별도로 보존했다.

이 표본은 같은 스타일 쌍과 미관측 스타일을 확인하려고 선택한 목적 표본이다. 실제 전체 품질,
서로 다른 제조사·주종·포장/용량 일반화, 독립 인간 판단, 최종 holdout·선호/CTR·구매 전환을
평가하지 않았다. SVD를 fit/채택하지 않았고 전체 AI03·실서비스 카탈로그/Backend B1 연결은
미완료다. 다음은 허용 상품군/포장 다양성·별도 평가 명세 확대이며 미래 사용자/로그를 기다리지 않는다.
