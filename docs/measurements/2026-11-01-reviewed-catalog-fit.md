# 실제 원천 기반 업무 DEMO fit 관측

- 기준 main `7cc9cea`, Python3.12.14·잠금 scikit-learn1.9.1. 비교는 동일 명시 카탈로그와
  같은 필수/제외/limit에서 기존 B0/B1을 실행한 기능·정보 보존 검사다. 지연/성능 실험이 아니다.
- 원천4항목 중 검수 포장1개/1그룹을 전용 업무 DEMO에 연결했다. 업무 API의 반환 ID만
  매핑하고 도수/용량·전체 응답·snapshot hash/freshness를 검증했다. 주종은 수동 업무 분류,
  3000원은 명시 DEMO가격이고 가용성은 공개 탐색 목적의 행 존재/시연 선택이다.
- fit 전 고정 사실 명세와9개 시나리오를 파일/hash/UTC 시각에 결속했다. 이후 결과로 기대값을
  고치지 않았다. 실제 raw/spec/curation/mapping/snapshot·모델 파라미터/케이스 원응답은 ignored다.

| 실제 관측 | 값과 해석 |
|---|---|
| 학습 상품/그룹 | 각각1, known-catalog 표현 |
| TF-IDF | 업무 주종1어휘, IDF1.0. 원천 상품명/외부 본문·맛/향을 학습하지 않음 |
| 도수 | 관측1·누락0, min=max5vol%, 상수라 거리 비활성 |
| 용량 | 관측1·누락0, min=max500mL, 상수라 거리 비활성 |
| 미확인 맛/향 | 각각1/1 null. 검수된 빈 배열0/1 |
| 고정 사실/제약 | B0/B1 같은 후보·조건에서9개 통과, 순위 품질 지표가 아님 |
| 모델 fingerprint | `92626f2e69f19009de9e585c39a48b54b1a1f511609c864ff699f33149982349` |
| 학습 입력 hash | `74e1058498e71687b146af373bf55a228fdb9dfee43faa4b9018f831fda2d938` |
| 재현 | 같은 raw/spec/snapshot/mapping으로 두 실행의 fit 요약·어휘/IDF·fingerprint/케이스 동일. 실행 시각만 구분 |

추가 원천 확대는 공식 WDQS에 명시 can/bottle P31·양수 P2234/P2665, LIMIT10의 발견 GET1회를
실행했다. HTTP200·204B로 기존 후보1ID만 반환되어 신규0이었다. 해당 조건의 목적 표본이며
Wikidata 전체의 주류 부족을 증명하지 않는다. 즉시 재시도/조건 완화 우회를 하지 않았고 추가
Action API 원문 GET도 하지 않았다. 권리·bottle 분류는 공식 자료로 확인하되 원천 이미지는 제외했다.

독립 관련성 라벨·사용자/시간 분리·다중 상품군 holdout이 없으므로 Recall/NDCG/CTR·전환·
만족도·일반화 성과를 계산하지 않았다. B0/B1의 동일한 단일 결과를 순위 개선이라고 하지 않는다.
다음은 허용 제품 다양성 확대·개별 변형/단위 검수·튜닝 전 관련성/사실 명세와 다중 그룹 분리다.
