# 실제 CC0 상품군 표현의 고정 분할 실험

기준 커밋은 `a1f2578`이고 Python3.12.14·잠금 scikit-learn1.9.1/NumPy2.5.4를 사용한다.
실행 목적은 소량 원천의 실제 표현 fit·누수/unknown·표현 한계를 확인하는 것이다. 지연이나
사람 선호·서비스 추천 품질 개선 실험이 아니며 변경 전후 성능 수치를 만들지 않는다.

## 학습 전 고정한 원천과 사실

이전 실행에서 검수한 CC0 snapshot6항목 중 **product_family5개만** 사용한다. 브랜드1개는
선택하지 않았다. 외부 포장 SKU 근거를 추가 탐색했지만 이번에 확정하지 못했으며 이미지 파일명의
용량을 상품 용량으로 쓰지 않는다. H8에서 새 원천 수집·이미지/외부 리뷰 다운로드는 하지 않았다.

- 원문 SHA-256: `7250e348a35485201f728e87c97f633e7bf34bb77e69241695308055b3acf6ca`
- 최초 수동 사실/분할 명세: `67c75927eca6157a0d78cb86c7b06b417dcd2d34340949e227dfed1591811098`
- 첫 fit 전에 receipt/evidence 구분을 추가한 실행 명세: `4ff70d5ee55c3794fdcdc2fd0c0fee0bcbab2fee490f700eca84f762d8b45c82`

두 명세의 상품군·사실·3/2 분할은 동일하다. 원문/검수/영수증·명세·학습 출력은 ignored에
보존한다. source QID/revision별 개별 카탈로그·값을 공개 fixture나 Backend 업무 DB로 복사하지 않는다.
학습 명세는 P31/P176·도수/용량의 검수 사실이며 관련성 라벨이나 사람의 취향 정답이 아니다.

## 관측 결과와 해석

| 관측 | 실제 결과 | 의미/제약 |
|---|---|---|
| 선택 단위 | 5상품군, 동일 제조사1곳 | 판매 SKU/국내 카탈로그 대표 표본이 아님 |
| 학습/변환 | 3상품군 / 2상품군, 명시 그룹 교차0 | source 상품군 분리이지 최종 신규 SKU holdout은 아님 |
| 실제 TF-IDF 학습 | 3×5 희소 행렬, rank3 | 제조사1·주종 클래스4의 어휘/IDF를 fit |
| 학습 도수 | 관측3/3, 최소5.5%·최대10% | 변환 도수를 fit에 포함하지 않음 |
| 학습 용량 | 관측0/3, all_unknown·비활성 | 가짜 용량/0mL·관측 범위를 만들지 않음 |
| 변환 텍스트 | 각2토큰 중1지원·1OOV, 전체 OOV2/4 | 알려진 제조사만 공유하며 주종2토큰은 미등록 |
| 변환 도수 범위 | 학습 범위 밖1/2 | 5.3%를 -0.04444…로 변환·clip하지 않음 |
| 변환 용량 | 미관측2/2, scaled null | unknown과 실제0을 혼동하지 않음 |
| 판매 SKU·Backend 매핑·서비스 B1 fit | 각각0 | source 표현 학습과 구분 |

학습 fingerprint는 `33ee939a443d1860a6ac4aa046367f773422eb9920def5aa57c806ff637881dd`다.
학습 상태 검사는 사전 사실 기반의 vocabulary·DF-IDF·관측 수치 범위와 일치했다.
주종 OOV가 있어도 제조사 토큰이 남아 norm은0이 아니었다. **0이 아닌 벡터가 관련성이나
사용자 취향을 설명한다는 보장은 없다.** 정확한 클래스 ID만 사용했으므로 주종의 상하위 관계나
비슷한 이름의 의미를 배웠다고 주장하지 않는다. 관련성 평가 없이 새 모델을 서비스에 채택하지 않는다.

M1/TruncatedSVD는 이번 실험에서 미채택이다. 실제 학습 행3·차원5·rank3의 작은 표현이며
축소된 표현이 보존해야 할 독립 관련성/운영 목표와 카탈로그 다양성이 아직 부족하다. SVD fit을
실행했다고 쓰지 않고 충분한 데이터·평가 조건에서 비교를 다시 수행한다. Recall/NDCG도 독립
관련성 라벨이 없어 미산출이며 표현 rank·OOV를 만족도나 CTR로 바꾸지 않는다.

## 재현·안전성

명령은 [모듈 실행 안내](../SOURCE-FAMILY-EXPERIMENT.md)를 따른다. 동일 원천/명세의 새 출력으로
재실행하고 학습 fingerprint·파라미터와 transform 결과를 비교한다. 기존 보고서를 덮어쓰지 않는다.
collector의 manifest 모델 해시와 파일 바이트 해시의 차이로 첫 시도가 안전 보류됐고, 두 의미를
분리해 실제 collector receipt를 사용하는 회귀/배포 검증으로 연결했다. 이를 과거 운영 장애로 표현하지 않는다.

외부 사용자가 없어도 이 학습/분할 실험은 수행했다. 서비스 SKU/권리/포장 대응·특성 다양성,
독립 카탈로그 관련성·최종 평가와 실제 모델 서비스 연동은 미완료다. 허구 fixture는 코드 회귀만
검증하며 이 표의 실원천 관측 수치와 섞지 않는다.
