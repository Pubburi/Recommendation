# DAT01 구조화 원천 표본 감사와 오프라인 준비 도구

- 기준 main: `95f22d7de84b037a029292dfcc721d6e923760c3`.
- 범위: 공식 원천의 권리/필드 확인, 허용된 소량 표본과 unknown·단위·정체성 감사 코드.
  모델 학습·서비스 상품 수집 완료·Backend 업무 DB 변경과 구분한다.
- aT 상세의 무료/제한 없음과 판매자 허락·상업 협의·공란 유의사항을 함께 확인했다.
  16컬럼/1251행은 메타데이터로만 기록한다. 실제 CSV의 결측·중복 수치로 쓰지 않는다.
- 공개 다운로드 메타데이터 POST가 제3자 권리/학습·재배포 조건 미확인 위험으로 자동 승인
  검토에서 거절됐다. 재시도/간접 다운로드를 하지 않았다. 상업 협의만으로 비상업을 금지한
  해석과 구분하고, 원천 명세에 이번 보류 사유를 보존했다.
- 독립 대안인 Wikidata의 공식 CC0 구조화 라벨/claim을 사전 확인하고 Action API로 4개
  항목만 조회했다. 이미지·위키 본문·외부 소개글·사용자 후기를 수집하지 않았다.
- `catalog_audit`는 명세 허용을 먼저 확인하는 오프라인 CLI다. 알려진 단위 변환, 범위/문맥/
  충돌/unknown, deprecated 제외, entity revision·원문 SHA-256, 정체성/검수 mapping을 분리한다.
- 원천 ID/브랜드를 상품/SKU로 자동 변환하지 않는다. 명시 검수 SKU·Backend ID·그룹·시연
  가용성/가격으로만 B0 demo 요청을 내보내며 정규화 원천 가격은 계속 unknown으로 남긴다.
- 실제 목적 표본: 4 entity, 브랜드3·미확정1·검수SKU0, 라벨 결측1/4·도수 결측1/4·용량/
  가격/그룹 결측4/4, B0 export0. 표본의 선택/구조적 한계와 일반화 불가를 명시한다.
- 원문/전체 정규화 데이터/검수 mapping/실행 결과는 ignored에만 둔다. 출력 경로는 `.pubburi`
  아래의 새 폴더로 제한하며 기존 감사 결과를 덮어쓰지 않는다. Git에는 명세/도구/직접 작성
  가상 fixture 테스트/집계·한계만 남긴다.
- 검증은 입력 범위·권리 보류 선확인·수량 단위/충돌·브랜드/SKU 분리·해시·명시 ID/시연 가격·
  내보내기·기존 run 보존을 수행한다. 새 배포 wheel에서 CLI 실행/기존 HTTP도 유지한다.
- 최종 `./scripts/check.sh`에서 저장소/locked/Ruff·pytest81·새 sdist/wheel·runtime-only 설치·
  checkout 밖 CLI help와 실제 health/B0/OpenAPI/중복422를 통과했다. 기존 TestClient 사용 중단
  경고 1개는 남아 있다. 최종 코드로 실제 표본을 다시 처리한 두 실행의 감사/정규화 JSON도 일치했다.
  테스트 수·CLI 실행 시간은 서비스 성능 또는 추천 품질 개선 수치가 아니다.
- README 사례는 현재 2/4를 유지한다. 이번 감사는 모델 평가/누수 차단 실험까지 완료하지
  않았으므로 REC-CS04를 성급하게 승격하거나 검증 개수로 새 사례를 채우지 않는다.
- 남은 일: aT 획득/권리 검토의 실제 차단 해소 또는 충분한 허용 대안, 실제 판매 SKU/변형군·
  명시 주종/가격 성격 검수, 기존 시드/이미지 감사, B1 fit·관련성 명세·학습/검증/최종 평가.
